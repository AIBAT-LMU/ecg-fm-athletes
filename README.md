# ecg-fm-athletes

Code for "ECG Foundation Models for Cardiovascular Screening in a Cohort of Young Competitive Athletes": fine-tuning and evaluation of ECG-FM, HuBERT-ECG and ECGFounder on PhysioNet/CinC 2021 and an elite athlete cohort.

## Status

The manuscript is currently under review at *npj Digital Medicine*.
The code for preprocessing, fine-tuning, evaluation and statistical analysis will be released in this repository upon publication.

## Data

- **PhysioNet/CinC 2021**: publicly available via [PhysioNet](https://physionet.org/content/challenge-2021/1.0.3/)
- **CODE-15%**: publicly available via [Zenodo](https://doi.org/10.5281/zenodo.4916206)
- **LMU athlete dataset**: not publicly available due to data protection regulations; available from the corresponding author on reasonable request, subject to ethics approval and a data use agreement.

## Models

- [ECG-FM](https://github.com/bowang-lab/ECG-FM)
- [HuBERT-ECG](https://github.com/Edoar-do/HuBERT-ECG)
- [ECGFounder](https://github.com/PKUDigitalHealth/ECGFounder)
